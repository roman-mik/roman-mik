## Featured project — [Kapa](https://github.com/roman-mik/kapa)

A monthly spending-cap tracker: one cap, every expense logged in two taps, always know what's
left. [Live demo →](https://expenses-tracker-kapa4.vercel.app)

Built as a pnpm + Turborepo monorepo on Next.js App Router and Supabase/Postgres, with a
production pipeline where a merged release-please PR applies database migrations *before*
deploying the code that depends on them, CI that regenerates and diffs generated DB types on
every schema change, and a household data model backed by row-level security.
